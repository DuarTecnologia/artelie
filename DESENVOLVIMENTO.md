# ArteLiê — primeira versão visual
Node.js 22 recomendado. Execute npm install, npm run typecheck, npm run build e npm run dev. Abra http://localhost:3000. Na Vercel importe o repositório e selecione Next.js. As cinco migrações existentes permanecem intactas. O catálogo e painel são demonstrativos; carrinho local, sem checkout real. Login desativado. Não inserir dados pessoais. A rota /admin é uma prévia pública sem dados privados. Antes de produção, proteger rotas no servidor, implementar API, validar RLS e funções transacionais, conectar Storage e Mercado Pago. Copie .env.example para .env.local quando integrar o Supabase; nunca exponha service_role. As ilustrações SVG são temporárias e a narrativa institucional é fictícia.
